# World Time Zones Clock

App show local machine time in UTC and time in other time zones on world map.
Small recruitment project for frontend developer position.

### Tech stack

- React
- TypeScript
- CSS
- Vite
- Jest
- React Testing Library
- GitHub Pages (hosting)
- RWD (Responsive Web Design)

### Functionalities

- Start time on main clock is actual time in UTC from local device time.
- User can grab tip and change time by dragging to another hour on shield forward or backward.
- Only main big clock is interactive.
- Two small clocks show +1h / -1h offset from main clock time.
- User can see time in other time zones on map.
- When user change hour on main clock shield - time in small clocks is updated automatically.
- When user change hour on main clock shield - time zones in world map is updated automatically.

### Installation

```bash
npm install
npm run dev - run on localhost
npm run deploy - to build the app on GitHub Pages
npm run test:watch - run tests in watch mode
```
